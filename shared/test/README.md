# Что проверяют тесты

Ожидаемые суммы задаются числами, рассчитанными независимо от проверяемой
функции. Примеры тарифов опираются на [юридическую сверку](../LEGAL_REVIEW.md).
Справочные примеры используют фактические изменения ставки и БВ. Явные
пользовательские ставки допустимы там, где это предусмотрено контрактом.

| Набор | Для чего нужен | Примеры ошибок, которые должен обнаружить |
| --- | --- | --- |
| `shared.test.cjs` | Арифметика, тарифы, календарь, совместимые функции библиотеки | Пропущен последний день; неверный делитель високосного года; округление до завершения периода; неверная ступень или минимум пошлины; границы 100/300 БВ; льгота применена на неподдержанной стадии |
| `schemas.test.cjs` | Правила допустимого запроса | Строка вместо числа; дата со временем; отсутствуют ставка, исходное требование или дата события; дневной пене передан годовой параметр; ошибочная строка пакета не определена в `issues` |
| `referenceData.test.cjs` | Выбор фактических данных, результат, отображение, НБРБ | Ставка взята по концу периода вместо даты события; строки пакета получили один справочник; нулевая ставка заменена справочной; кэш смешивает даты; сбой НБРБ скрыт; таймаут не срабатывает |
| `contracts.test.cjs` | Настоящий HTTP-запрос через Express, JSON и обработку ошибок | Маршрут потерял юридический параметр; сервер подставил ставку вместо нуля; ошибка схемы стала HTTP 500; некорректный JSON/слишком большое тело дали другой формат ошибки; GET проигнорировал дату |

Проверка границы тарифа в ядре и выборочная проверка передачи параметров через
HTTP имеют разные цели. В HTTP не повторяется вся таблица тарифов или матрица
ошибочных значений. Схемы проверяются без запуска сервера.

## Что убрано или заменено

- Сравнения ответа сервера с результатом другой обёртки той же функции:
  одинаковая ошибка в обеих ветках давала успешный тест. Вместо этого заданы
  независимые ожидаемые суммы и значимые поля ответа.
- Повторные матрицы `annualRate × rate × endpoint` и проверки одного неверного
  долга через все обёртки. Сохранены классы ошибок и отдельные HTTP-проверки
  передачи нулевой ставки.
- Полный повтор проверки 100/300 БВ на каждом уровне. Суммы на порогах и на
  копейку ниже/выше проверяются в тарифном ядре для обоих видов суда.
- Подмена БВ на 50 BYN и исторической ставки на 10% ради подсчёта обращений
  к функции, проверка идентичности объектов. Теперь проверяются итоговая сумма,
  фактическая запись и её отображение. Число сетевых запросов проверяется
  только там, где оно определяет работу кэша.
- Расчёты по ст. 366 за 1900 год и будущая ставка 8%, которой нет в справочнике.
  Для выбора ставок используется реальная граница 31.05/01.06.2026.
- Прямой вызов приватной цепочки `app._router.stack`: он обходил разбор JSON
  и middleware, хотя назывался HTTP-проверкой. Такие сценарии перенесены
  в HTTP-набор.
- Проверки фильтрации каталога льгот по заявителю и стадии: существующая
  `getDiscountsForCourt` принимает только суд и вид дела. Эти дополнительные
  параметры не являются реализованным контрактом функции.

Маленькая сумма и половина копейки нужны для проверки округления, а не для
моделирования судебного дела. Например, два начисления по 0,005 BYN должны
дать 0,02 BYN после округления строк, тогда как промежуточное округление
частей одного годового расчёта запрещено. Два прежних теста на суммах,
при которых результат не менялся от промежуточного округления, заменены
примерами, на которых ошибка проявляется.

Сбой соединения, HTTP 503, неверный JSON, некорректная запись и зависание
чтения тела — необходимые режимы проверки внешнего сервиса. Они имитируются
локально; постоянный доступ к НБРБ не нужен. Удалены дополнительные переборы
замоканных значений одного класса; проверка конечности чисел остаётся
на границе арифметического ядра.

## Известное реальное расхождение

Тест `alimony catalog entry agrees with the legal basis documented in
LEGAL_REVIEW.md` остаётся падающим: юридическая сверка указывает подпункт
`1.1.2`, а `articleRef` в `calculate/discounts.ts` ссылается на `1.1`.
Проверяется правовое основание, а не внутренний ID записи или формат строки.
Тест использует существующий API с двумя аргументами. Дубли и проверки
отсутствующих параметров удалены, но это расхождение не скрыто изменением
ожиданий под текущий код. Юридические данные каталога в рамках ревизии тестов
не менялись. Проверки освобождения в самом расчёте пошлины сохранены.

## Запуск

Из корня проекта:

```sh
npm run test:unit -w shared
npm run test:contracts -w shared
npm test -w shared
npm run typecheck -w shared
node node_modules/typescript/bin/tsc -p client/tsconfig.json --noEmit
```

`test:unit` выполняет арифметику, схемы, выбор справочников, отображение и
имитацию НБРБ без сетевых соединений. HTTP-набор открывает временный порт
на `127.0.0.1`; ему требуется разрешённое локальное соединение.
`npm test` запускает оба набора. Сборка проекта для тестов не нужна.
