# Контракты расчётов

`src/contracts` экспортирует схемы `.parse(unknown)`, типы запросов и ответов,
а также функции `calculate*Request`. Клиент проверяет форму перед `fetch`, API
проверяет JSON до расчёта теми же схемами. Неизвестные поля отклоняются, чтобы
новый параметр не терялся молча. При ошибке API возвращает HTTP 400 и
`{ error, issues: [{ path, message }] }`; путь документа — `documents.1.debt`.
Пакет проверяется целиком до первого расчёта.

Все транспортные даты — существующие календарные даты `YYYY-MM-DD`.
Объекты `Date`, временные метки и строки с часовым поясом в запросах запрещены.
Момент обновления справочника (`updatedAt`) остаётся временной меткой.
Денежные значения — числа BYN с точностью до копейки; ставки — конечные
неотрицательные числа. Строки вместо чисел не преобразуются. Ставка `0` допустима.

| Сценарий | Обязательные поля |
| --- | --- |
| Любая пошлина | `courtType`, `plaintiffType`, `caseType`, `date` обращения |
| Имущественное требование, спор о качестве, приказ | Дополнительно `amount > 0` |
| Жалоба | Оспариваемая `amount` либо `originalCaseType` |
| Экономическая жалоба без суммы | Если исходный тариф зависит от суда — `originalCourtLevel` |
| Административная жалоба (включая исходное требование) | `administrativePenalty: fine/other`; для `fine` также `fineAmount > 0` |
| Пеня | `debt`, `startDate`, `endDate`, явная дневная `rate` |
| Годовые проценты | `debt`, `startDate`, `endDate`, `annualRate`, `dayCount`; дневная `rate` одновременно запрещена |
| Статья 366 | `debt`, `startDate`, `endDate`, `calculationBasis`, явный `hasPenalty` |
| Статья 366: оплата, решение, исполнительная надпись | Дополнительно `rateDate`, `dayCount` |
| Статья 366: несколько лет | Явный `dayCount`, в том числе для предварительного расчёта |
| Статья 366 с неустойкой | `statutoryException: true` |
| Любой пакет | Непустой `documents`; у каждой строки `name`, `debt`, `startDate`, `endDate` |

Суды: `common`, `economic`, `appellate_economic`, `supreme_economic`.
Заявители: `individual`, `organization`, `ip` (последний в экономических судах).
`ip` больше не является видом суда. Общий суд допускает также организации;
экономический — также физических лиц. Виды требований проверяются по суду
и типу заявителя.

Для жалобы `originalCaseType` не может быть другой жалобой. Имущественное
исходное требование требует оспариваемой суммы. `isRepeated` передаётся
для повторного брака, в том числе в исходном требовании. Отдельный вид
`contract_dispute` не подменяет общий неимущественный иск.

`dayCount`: `360`, `365`, `366` (числа), `start-year`, `end-year`, `actual/actual`.
Основания ст. 366: `payment`, `judgment`, `executive-endorsement`, `estimate`.
`rateDate` не подменяется датой окончания для юридических оснований.
В `estimate` пропущенная дата ставки заменяется концом периода с предупреждением.
Необязательная `refinancingRate` задаёт явную ставку; источник отражается в ответе.
Параметры ставки, основания, неустойки и делителя задаются на весь пакет;
переопределения в строках отклоняются.

Пример запроса на `/api/interest/calculate-366-multiple`:

```json
{
  "documents": [{ "name": "Договор", "debt": 10000, "startDate": "2026-05-01", "endDate": "2026-05-31" }],
  "calculationBasis": "judgment",
  "rateDate": "2026-06-01",
  "dayCount": "actual/actual",
  "hasPenalty": false
}
```

Ответ сохраняет суммы и добавляет `methodology`, `rulesVersion`, `referenceData`
и `warnings`. Снимок справочной записи содержит дату выбора, значение и акт;
для проверенных ставок — источник и дату проверки. Строка ответа ст. 366 и
ответ пошлины также сохраняют `input` для проверки полноты передачи условий.
У пакета ст. 366 справочники сохраняются в каждой строке: в предварительном
режиме даты выбора ставки могут различаться. Предупреждения агрегируются
на уровне пакета и показываются клиентом.

Начало периода — установленный первый день просрочки; оба края включены.
Округление — до копейки, половина вверх. Итог — точная сумма округлённых строк.
Снимок тарифов пошлины поддерживает 2026 год; другие годы отклоняются.
Встроенные справочники не заменяют онлайн-проверку актуальности.

## Проверка

Из корня: `npm run test:contracts -w shared`, `npm run typecheck -w shared`,
`node node_modules/typescript/bin/tsc -p client/tsconfig.json --noEmit`.
HTTP-тестам требуется локальное соединение с временным портом на `127.0.0.1`.
Полный набор: `npm test -w shared`. В существующем наборе остаются два
несоответствия старого каталога льгот сохранённой юридической сверке
(`discount lookup…`, `Article 285 exemptions…`); каталог не входит в эту интеграцию.
